# `src/resources/l10n`

Catálogos de tradução. Cada arquivo é um JSON de pares `chave → texto`. `LocalizationProvider` carrega o idioma ativo e `t('chave')` devolve o texto. O inglês (`en.json`) é a fonte; o Transifex (`.tx/config`) gera os outros a partir dele.

Não há classes. São dados, não código.

Se uma chave falta no idioma escolhido, a interface cai no inglês.
