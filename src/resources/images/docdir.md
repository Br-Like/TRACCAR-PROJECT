# `src/resources/images`

SVGs desenhados pelo mapa e pelas telas de login. `preloadImages.js` e `mapUtil.js` rasterizam estes arquivos para o MapLibre usar como ícone.

## `logo.svg`

Logotipo padrão, usado quando o servidor não envia uma imagem própria.

## `background.svg`

Fundo do marcador de dispositivo (a “gota” ou o círculo sobre o qual o ícone da categoria é desenhado).

## `direction.svg`

Seta de direção. Gira conforme o rumo (`course`) da última posição, para mostrar para onde o veículo aponta.

O ícone de categoria padrão fica em `data/`.
